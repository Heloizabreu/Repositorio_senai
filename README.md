Exercício 1:
O programa percorreu os números de 0 até 100 e mostrou quais são pares e quais são ímpares.

Exercício 2:
O código pediu 3 números ao usuário, guardou eles em uma lista e depois mostrou o maior e o menor valor digitado.

Exercício 3:
O programa pediu um nome e foi mostrando as letras aos poucos, formando uma “escada”.

Exercício 4:
O código gerou a sequência de Fibonacci até a quantidade de termos escolhida pelo usuário.

Exercício 5:
O programa validou as informações digitadas pelo usuário, verificando se os dados estavam corretos.

Exercício 6:
O código verificou se o número digitado é primo, ou seja, divisível apenas por 1 e por ele mesmo.

Exercício 7:
O programa calculou o fatorial do número digitado utilizando o laço FOR.

Exercício 8:
O código analisou a lista e mostrou tamanho, maior valor, menor valor, soma e a lista em ordem crescente e decrescente.

Exercício 9:
O programa criou um dicionário representando os produtos e preços da lanchonete.

Exercício 10:
O código pediu uma senha ao usuário até que a senha correta fosse digitada.

Exercício 11:
O programa mostrou a tabuada do número escolhido pelo usuário.
